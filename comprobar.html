¿Está tu web preparada para los agentes de IA?

Ingresa la url o dirección de tu web y comprobamos gratis 7 puntos clave para que ChatGPT, Claude, Gemini, Perplexity y otras IA puedan encontrarla y leerla.

Por ejemplo: www.miweb.com. No hace falta escribir https://.

Después del análisis te pediremos tu email para mostrarte el resultado.

Qué revisamos

  • Archivo robots.txtUn archivo que dice a los robots qué partes de tu web pueden visitar.
  • Mapa del sitio (sitemap.xml)La lista de las páginas de tu web, para que no se les escape ninguna.
  • Cabeceras LinkSeñales invisibles que apuntan a los agentes hacia lo más útil de tu web.
  • Contenido en Markdown para agentesUna versión en texto simple de tus páginas, fácil de leer para una IA.
  • Reglas para rastreadores de IAQué bots de IA pueden entrar a tu web y cuáles no.
  • Señales de uso de contenidoSi permites que las IA usen tu contenido, y para qué.
  • Índice de Agent SkillsUna lista de lo que un agente puede hacer en tu web, como reservar.
